======================================================================
1. BIG TOP WILDS — AUTHORITATIVE CURTAIN FEATURE
======================================================================

The old visual interpretation in which a curtain occupies one ordinary symbol cell is INVALID.

The Curtain Feature is a reel-level feature object.

REEL GEOMETRY:
- 6 reels.
- each reel has 2–6 visible cells;
- reel viewport width is fixed for current breakpoint;
- reel viewport height is fixed for current breakpoint;
- each reel width is constant;
- cell height varies with rowCount;
- Curtain overlay width = EXACTLY one reel width;
- Curtain overlay height = EXACTLY 100% of the visible reel viewport height.

Curtain must never span multiple reels unless a future explicit feature says so.
Curtain must never be confined to the trigger cell.
Curtain must not resize the reel, cell grid, slot frame, or HUD.

======================================================================

SHOW TICKET visual:

- clear word SHOW;

Important separation:

Curtain exists as a full-reel animation overlay created AFTER the reel settles.
Never draw SHOW TICKET on the curtain itself.

Recommended state:

  }
]

All trigger outcomes must be known before presentation begins.

======================================================================
3. BIG TOP WILDS — CURTAIN ANIMATION, FRAME BY FRAME
======================================================================

The approved feature should read as a miniature stage show inside ONE reel.

PHASE 0 — REELS SETTLE
- All normal reel motion finishes first.
- SHOW TICKET remains visibly located in one cell of the triggering reel long enough for the player to understand what triggered the event.
- Other reels remain still.
- Do not start clown animation while normal reel motion is unfinished.

PHASE 1 — REEL TAKES FOCUS
- triggering reel receives a short warm spotlight/glow around its reel frame;
- neighboring reels may dim slightly;
- no geometry changes;
- SHOW TICKET can pulse briefly.

PHASE 2 — CURTAINS CLOSE OVER THE FULL REEL
Preferred animation:
- two red velvet curtain halves enter from LEFT and RIGHT edges of the triggering reel;
- they move toward the horizontal centerline of that reel;
- each curtain half covers approximately half the reel width when fully closed;
- combined curtains cover 100% reel width;
- curtains extend from top to bottom of the reel: 100% reel height;
- top valance and bottom decorative trim may be present but must remain inside reel bounds;
- curtain layer clips inside the reel container.

Alternative top-down drop is allowed only as a secondary flourish. The PRIMARY readable motion must be a real theatre-style left/right close/open interaction.

Timing target in Normal mode:
- focus/pulse: ~180–260 ms;
- curtains close: ~320–480 ms;
- brief closed hold: ~120–220 ms.

Quick/Turbo may shorten timings but preserve all semantic stages.
Reduced Motion may crossfade between states without losing meaning.

PHASE 3 — CURTAINS OPEN TO A STAGE
- both curtain halves pull back toward the left/right sides of THE SAME reel;
- curtain remains visually present at both sides as an OPEN stage frame;
- interior becomes a stage area;
- the stage is clipped to the reel rectangle;
- the curtain does NOT disappear entirely;
- no content may overlap neighboring reels.

PHASE 4 — BOMBO VS SKINNY SHOWDOWN INSIDE OPEN CURTAIN
ABSOLUTE CHARACTER RULE:
Use ONLY the two approved BIG TOP WILDS characters:
- BOMBO = huge, round, heavy, clumsy physical-comedy clown;
- SKINNY = extremely thin/tall, elastic, agile trickster clown.

Source-of-truth character identity:
06_REFERENCES/BIG_TOP_APPROVED_BOMBO_SKINNY_source.webp
and the original BIG TOP baseline package.

Do NOT:
- create a new red clown;
- create a new blue clown;
- substitute generic clown art;
- use clowns visible in intermediate reference mockups if they do not match BOMBO/SKINNY;
- change their body shapes to make them look like siblings/variants of the same model.

Within the stage:
- BOMBO and SKINNY enter from opposite vertical zones or opposite sides;
- both must remain fully inside the opened curtain/reel bounds;
- their silhouettes must stay distinct;
- interaction should feel comic, not violent or frightening;
- example motions: tugging the curtain rope, comical shove/pull, prop trick, bounce, dodge, balance gag;
- outcome is already defined in featurePlan;
- animation only presents the predetermined winner.

Target showdown length Normal: ~650–1100 ms.
Do not let this become a multi-second unskippable cutscene.

PHASE 5 — WINNER TAKES THE REEL
- losing clown exits/falls/slides out INSIDE the stage bounds;
- winner becomes the sole focal character;
- winner visually expands/recomposes to occupy the full-reel stage composition WITHOUT non-uniformly stretching the face/body;
- use scale/reposition/recompose, not distortion;
- open curtains remain visible at the reel sides/top as framing.

PHASE 6 — FINAL STATE IS ALWAYS OPEN
This is mandatory.
The final Curtain Feature state must NOT close again.
The reel remains an OPEN circus stage after the duel.
Exactly ONE approved winning clown is visible.
Final reel label/result is visible with that clown.

Final states:
- multiplier = 1 => label displays only WILD;
- multiplier = 2 => label displays only x2;
- multiplier = 3 => label displays only x3;
- multiplier = 5 => label displays only x5;
- multiplier = 10 => label displays only x10.

CRITICAL:
Do not show 'WILD' plus an additional xN badge for multiplier states.
xN REPLACES WILD label in the same decorative result/plaque zone.
No black generic badges.

The final open-stage feature occupies:
width = 100% of one reel width;
height = 100% of reel viewport height.

PHASE 7 — WIN EVALUATION / PRESENTATION
- only after all triggered Curtain reels reach their final state;
- evaluate the paid result once according to existing BIG TOP WILDS math;
- no cascade created by curtain presentation;
- no additional RNG after reveal;
- settlement remains idempotent.

5. FULL REEL WILD / MULTIPLIER BEHAVIOR
======================================================================

The resolved Curtain reel behaves as one full-reel Wild feature.
It visually represents Wild coverage for every visible cell on that reel.

If reel has 2 rows: feature covers both rows.
If reel has 6 rows: feature covers all six rows.
Any 3/4/5-row state behaves the same.

Multiplier belongs to the Curtain REEL, not to each cell independently.
Do NOT apply x3 six times because a six-row reel has six Wild cells.
Use the existing BIG TOP multiplier math from the baseline package.

6. DYNAMIC BIG TOP WAYS DISPLAY
======================================================================

The slot must display the CURRENT ways count dynamically every spin.

Do not use the trademarked word MEGAWAYS in visible UI.
Visible copy:
BIG TOP WAYS
or
[NUMBER] WAYS

Current ways formula:
currentWays = product(reelHeights)

Example:
reelHeights = [4, 6, 3, 5, 4, 6]
currentWays = 8640
visible display = '8,640 WAYS'

Maximum theoretical configuration:
6 x 6 x 6 x 6 x 6 x 6 = 46,656 WAYS.

Behavior:
- determine reelHeights before visual spin;
- ways display may animate/count/morph as reels establish their final heights;
- by final settle it MUST show the exact current product;
- do not leave static 'UP TO 46,656' as the only information;
- 'UP TO 46,656' may remain secondary marketing copy, but CURRENT ways must be visible;
- currentWays is presentation only and must match engine state;
- no calculation from DOM pixel heights.

Responsive:
- never cause HUD width overflow;
- use locale/grouping formatter;
- mobile may use '8.6K WAYS' only if the exact current value is also accessible in feature/info UI; preferred visible value is exact formatted integer when space permits.
