# VAULT HEIST — vault scene presentation

Экран оформлен по предоставленному общему визуальному референсу: открытая дверь сейфа слева, камера артефакта справа, массивная металлическая рама и нижняя панель с круглой SPIN. Общая шапка VAULT и персональный баланс сохранены.

Новые самостоятельные художественные слои подготовлены по референсу:

- `assets/heist/scene-v2/environment.webp` — только окружение, 1672×941; без запечённых reels, текста или кнопок.
- `assets/heist/scene-v2/reel-frame.webp` — прозрачная металлическая рамка, 1402×1122; настоящие HTML-барабаны располагаются внутри прозрачного проёма.

15 утверждённых символов из пользовательского архива используются целиком, без изменения файлов. Их соответствия и контрольные суммы находятся в [HEIST_SYMBOLS.md](HEIST_SYMBOLS.md). Начальный экран без активного раунда показывает декоративную раскладку по референсу; оплаченные и восстановленные сцены всегда берутся из существующей модели.

Шесть этапов сверху отражают фактическое состояние ограбления. ALARM показывает реальную вероятность следующей проверки, включая текущие модификаторы. Таймер обратного отсчёта с макета не добавлен: такой механики в игре нет. Существующие настройки, помощь, ставка, MAX, AUTO и BONUS доступны в нижней панели. На телефонах панель перестраивается в два ряда; на коротких экранах доступна вертикальная прокрутка.

Математика, RNG, цены, выплаты, checkpoints, общий wallet/auth и остальной HTML за пределами трёх блоков HEIST сохранены. SQL для этого визуального обновления не требуется. Старые художественные файлы и предыдущий frontend сохранены; перед заменой создан `/workspace/output/VAULT_before_heist_scene.html`.

Последняя собранная версия проверена `python tools/heist-scene-check.py`: семь размеров экрана от 320 до 1600 px, целые прозрачные силуэты при пульсации выигрыша, все меню и контролы, уникальные ID, реальный выигрыш, бонусный этап, COLLECT и F5 без повторного списания/выплаты. Ошибок страницы и консоли нет. Использовались настоящий HTML и SDK авторизации с локальным HTTP fixture; production БД тест не изменяет. Отчёт: `reports/heist-scene-browser.json`.

Сборка и синтаксис: `python tools/build-site.py`, `node --check /tmp/digital-derby-release.js`. Изменения источников предварительно встраиваются существующим `tools/embed-vault.py`.
