1. BONUS PAYOUT SETTLEMENT — ALL SLOTS
==================================================
During any bonus game / free-spins session:
- DO NOT credit the wallet after each individual free spin.
- Accumulate all wins inside bonusSession.totalWin.
- Update only the visual BONUS WIN / current bonus total during the bonus.
- The real wallet balance must remain unchanged during the bonus session.
- When the entire bonus session is finished, credit the accumulated bonus result ONCE.
- Settlement must happen exactly once.

Required flow:
BONUS START
→ free spin wins accumulate in bonusSession.totalWin
→ final bonus spin
→ BONUS COMPLETE presentation
→ final bonus settlement
→ wallet += bonusSession.totalWin ONCE
→ return to base game

Reload safety:
- persist bonusSession.totalWin;
- persist settlement status;
- reload must never cause a second payout.

6. CRITTER CHAOS — BONUS WILDS
==================================================
Base game:
- Wild is a normal standard Wild;
- it does not move;
- it does not persist;
- no running-Wild logic in base game.

Bonus game:
- every landed Wild becomes persistent;
- every new Wild starts at x1;
- persistent Wilds remain for the entire bonus;
- each Wild keeps its own multiplier;
- after a Wild participates in a win, its multiplier doubles for future bonus spins.

Example:
x1 → win → x2
x2 → win → x4
x4 → win → x8
...

Multiple Wild multipliers in one win:
ADD them, do not multiply them.
Example: x8 + x2 = x10.

==================================================
