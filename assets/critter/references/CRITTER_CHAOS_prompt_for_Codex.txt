WILD MECHANIC
This slot should use a “running wild” mechanic.
- When a wild participates in a win, it becomes active.
- Active wilds move / run / jump to a new random position for the next cascade or next evaluation step.
- The movement should be visually fun and clearly readable.
- Wild movement should feel like the raccoon is causing chaos.
- If multiple wilds are active, each movement should resolve clearly one after another or in a well-readable sequence.

RECOMMENDED GAME FLOW
- Spin starts.
- Reels stop.
- Winning combinations are highlighted.
- If a wild is involved in the win, trigger the running-wild feature.
- Remove winning symbols if you use a cascading system.
- Refill reels.
- Re-evaluate wins.
- Continue until no more wins remain.
